\# Configuraciones



Archivos de configuración sanitizados (sin contraseñas ni secretos) de los routers del Lab 01.



\- \[`Rock1.txt`](Rock1.txt): LAN A, enlace con Rock2 y ruta predeterminada IPv4.

Para reproducir el lab, pegá el contenido de cada archivo en la consola del router correspondiente en Packet Tracer.
