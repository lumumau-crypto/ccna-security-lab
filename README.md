# CCNA + Ciberseguridad: laboratorios de redes

Portfolio de laboratorios de redes con enfoque en ciberseguridad (atacante y defensor).
Cada laboratorio incluye topología, configuración, evidencia y conclusiones.

**Herramientas:** Cisco Packet Tracer · GNS3 · Wireshark · Parrot Security · Ubuntu

> Todos los laboratorios se realizan en entornos aislados propios.
> No se incluyen datos personales, contraseñas ni IPs reales.
